# 喜鹊音乐酒馆 · 3D 场景 Demo

主网页「旅行相册」中的「喜鹊酒馆 Live Band」卡片已接入此 3D 场景。资料有限，属于同店实拍引导的概念重建，并非实测扫描。

## 运行

在 `D:\MMU\nanyang-3d` 执行 `python -m http.server 4181 --bind 127.0.0.1`，打开主网页 `http://127.0.0.1:4181/`，点击「喜鹊酒馆 Live Band」卡片进入 3D 场景。也可直接打开 `http://127.0.0.1:4181/magpie-bar-demo/`。不要直接双击 HTML。

## 模型与交互

`scene-builder.mjs` 生成有体积的外墙、地面、天花、门面、桌椅、舞台、乐器、灯具与装饰；`models/magpie-bar.glb` 是可复用的完整静态模型。`scripts/export-glb.mjs` 可重新导出。渲染使用本项目 `cave-dinner-demo/vendor` 中的本地 Three.js，不依赖 CDN。

鼠标/单指拖动环顾；WASD 或屏幕方向键行走；入口、卡座、舞台、吧台、全景快捷视角；点击热点查看说明。全景模式仅在浏览器里临时隐藏屋顶，下载模型仍含完整屋顶。支持演出/参观灯光、重置及减少动态效果偏好。
